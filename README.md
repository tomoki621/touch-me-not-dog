# 触らせてくれない

カメラに映った自分の手を検出して、近づくと剣で威嚇してくる犬。

- **`index.html`** — 本命。カメラ + 手の検出（MediaPipe HandLandmarker）
- **`tap.html`** — カメラなしのタップ版（手検出が使えない環境向け）
- **`build.sh`** — `tap.html` を Artifact 用の断片に変換

## 動かす

カメラは **HTTPS か localhost でしか許可されません**。`file://` や `http://192.168.x.x` では起動しません。

```sh
python -m http.server 8000 --bind 127.0.0.1
# → http://localhost:8000
```

スマホ実機は GitHub Pages 経由で開く。

## 実装メモ

**リギングをしていない。** 腕は肩から手先へ円柱を1本引き伸ばしているだけ（`stretchLimb()`）。
犬もすべてプリミティブ（球・円柱・円錐）で、外部アセットは0。

**動きはすべてプロシージャル。** 盾は手のいる方向へ毎フレーム lerp で回り込む。
この追従の遅れがそのまま攻略の隙になるので、ベイクしたアニメーションクリップでは代用できない。

**平面検知はしていない。** WebXR Hit Test は iOS Safari 非対応で、さらに immersive-ar
セッション中はカメラ映像のピクセルを取れないため、手検出と両立しない。
代わりに「犬を置く」でタップ設置し、接地感は影だけの床（ShadowMaterial）で出している。

**奥行きは手の見かけサイズで代用。** 単眼カメラなので真の深度は取れない。
手首(landmark 0)と中指付け根(9)の画面上の距離を近さの指標にしている。

**映像は object-fit: cover。** 正規化座標→画面座標の変換で、はみ出した分を
必ず打ち消すこと（`videoToScreen()`）。ここを省くと指先マーカーが数十pxずれる。
