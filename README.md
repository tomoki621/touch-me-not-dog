# 触らせてくれない

ルイーズのカードにかざすと、その上にルイーズが立つ。盾・威嚇・剣で追い払わせて撮るためのもの。

https://tomoki621.github.io/touch-me-not-dog/

| ファイル | 中身 |
|---|---|
| `index.html` | 本体。カードをマーカーにした AR |
| `compile.html` | カードの学習データ `targets.mind` を作るページ（PC で一度だけ実行） |
| `models/` | 減量済みの GLB 3体 |

## 準備

`targets.mind` が要る。`compile.html` を PC で開いて「学習をはじめる」を押し、
できたファイルをリポジトリ直下に置く。カメラは HTTPS か localhost でしか許可されない。

```sh
python -m http.server 8000 --bind 127.0.0.1
```

## 操作

カードを写す → その上に立つ → 右の3ボタン（盾・威嚇・剣）。
盾は押しっぱなしで構え続ける。キーの `1` `2` `3` でも出せる。
2本指で大きさとひねりの向き。位置と接地はカードが決めるので調整不要。

## 実装メモ

**カードが全部を教えてくれる。** 位置・向き・実寸が確定するので、以前やっていた
ジャイロによる水平の推測、カメラ画角の決め打ち、手動配置がまとめて不要になった。
影も実物のカードの上に落ちるため、接地は完全に成立する。

**リギングはしていない。** 腕は動かない。剣と盾は握りを支点に回し、構えでは
盾側の肩を前に出して半身になることで、腕が上がらないぶんを補っている。
チビ体型なら全身の踏み込みと回転でも斬撃は成立する。

**モデルは減量が必須だった。** Meshy の出力は 166MB / 508万三角形で端末に載らない。
gltf-transform で簡略化し、法線とメタリックのマップを外して baseColor だけを
1024/768 に落とし、3.1MB / 8.3万三角形にした。数センチの置物にそれらのマップは効かない。
元データは `3Dモデル/`（追跡しない）。

**Meshy はどの書き出しも同じ箱に正規化する。** 3体とも高さ 1.9 で出てくるので、
剣と盾の相対的な大きさと握り位置はコード側で組み直している（`fit()` と `HAND_L/R`）。

**手の検出は向きと遮蔽にしか使わない。** 技はボタンで出すので、認識が落ちても
撮影は破綻しない。遮蔽は手の形にマスクを作り、そこだけ実写を 3D の上へ描き戻す方式。
合成色ではなく本物のピクセルなので明るさも色も一致する。

**リポジトリに入れていないもの。** `ルイーズ.jpg`（カードのスキャン）と `3Dモデル/`（原寸 GLB）。
学習データ `targets.mind` は特徴点で、カード画像は復元できない。
