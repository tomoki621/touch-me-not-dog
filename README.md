# 触らせてくれない

カメラに映した机や床に犬を立たせて、盾・咆哮・剣で追い払わせる。撮って遊ぶためのもの。

https://tomoki621.github.io/touch-me-not-dog/

| ファイル | 中身 |
|---|---|
| `index.html` | 本命。カメラ背景 + 3ボタン操作（盾・咆哮・剣） |
| `hand.html`  | 手検出版。MediaPipe HandLandmarker で指先を追い、近づくと自動で反応する |
| `tap.html`   | カメラなしのタップ版 |
| `build.sh`   | `tap.html` を Artifact 用の断片に変換 |

## 操作

1. 画面タップでカメラ起動（ブラウザがユーザー操作を要求するので省略できない）
2. ドラッグで立ち位置、2本指ピンチで大きさ → 「ここに立たせる」
3. 右の3ボタン。盾は押しっぱなしで構え続ける。キーの `1` `2` `3` でも出せる

決定後はドラッグしないと犬は動かない（撮影中の不用意なタップで飛ばないように）。

## 動かす

カメラは **HTTPS か localhost でしか許可されない**。`file://` や `http://192.168.x.x` では起動しない。

```sh
python -m http.server 8000 --bind 127.0.0.1
```

## 実装メモ

**なぜ手検出をやめたか。** 参照動画の右側にあるのは盾・咆哮・剣の3ボタンで、
つまり本家も検知ではなく手動操作。撮る道具として見るなら、押した瞬間に必ず出るほうが
強い。8MBのモデル読み込み、誤検知、明暗への依存という不安定要因がまとめて消える。
検知版は `hand.html` に残してある。

**リギングをしていない。** 腕は肩から手先へ円柱を1本引き伸ばしているだけ（`stretchLimb()`）。
犬もすべてプリミティブ（球・円柱・円錐）で、外部アセットは0。

**平面検知はしていない。** WebXR Hit Test は iOS Safari 非対応で、さらに immersive-ar
セッション中はカメラ映像のピクセルを取れない。代わりに床平面へのレイキャストで設置し、
接地感は影（ShadowMaterial）だけで出している。

**ただし犬は端末の動きに追従しない。** world tracking がないので、スマホを動かすと
犬も一緒に動く。「その場に立ち続ける」を本当にやるなら ARKit / ARCore、
つまり Unity + AR Foundation の領域になる。
